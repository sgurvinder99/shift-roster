GITHUB PAGES — INSTALLABLE SHIFT ROSTER

1. Create a new GitHub repository, for example: shift-roster.
2. Upload every file from this folder to the TOP LEVEL of that repository.
   Important: index.html must be at the top level, not inside another folder.
3. In the repository, select Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose the main branch and / (root), then select Save.
6. After GitHub publishes the site, open the Pages URL on your phone:
   https://YOUR-GITHUB-USERNAME.github.io/shift-roster/
7. Android: Chrome menu (three dots) > Install app or Add to Home screen.
   iPhone: Safari Share button > Add to Home Screen.

The app works offline after its first successful load. Do not open index.html directly from the phone's Downloads folder: service workers and installation require HTTPS hosting.
