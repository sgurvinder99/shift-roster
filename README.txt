UPDATE YOUR EXISTING GITHUB SITE
1. Extract this ZIP on your computer.
2. Open your existing shift-roster repository on GitHub.
3. Use Add file > Upload files and upload the extracted files at the repository top level. Keep their original filenames.
4. Commit the replacements to the branch used by GitHub Pages.
5. Keep Pages enabled. Do not unpublish the site to update it.
6. After the deployment succeeds, open your existing website link and refresh.
7. If the installed app still shows an old month, close and reopen it after opening the website in your browser.
