GITHUB PAGES — INSTALLABLE SHIFT ROSTER (SEPTEMBER & OCTOBER 2026)

1. In your existing shift-roster GitHub repository, open Add file > Upload files.
2. Upload every file from this folder to the TOP LEVEL of that repository.
   Important: index.html must be at the top level, not inside another folder.
3. GitHub will flag files with matching names. Keep the uploaded replacements and click Commit changes.
4. The existing GitHub Pages setup and phone app shortcut can stay as they are.
5. After GitHub publishes, open or refresh https://sgurvinder99.github.io/shift-roster/ on your phone.
   If it still shows the old roster, close and reopen it, then refresh once more.
6. Android: Chrome menu (three dots) > Install app or Add to Home screen.
   iPhone: Safari Share button > Add to Home Screen.

The app works offline after its first successful load. Do not open index.html directly from the phone's Downloads folder: service workers and installation require HTTPS hosting.
